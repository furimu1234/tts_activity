# tts_activity

Discord のボイスチャンネル内のテキストチャットを読み上げる、Discord Activity
対応の Bot です。

## Bot を Discord サーバーに追加する

次のリンクをブラウザで開きます。

**[Bot を Discord サーバーに追加する](https://discord.com/oauth2/authorize?client_id=1163848386387116132&permissions=1024&integration_type=0&scope=applications.commands+bot)**

1. Discord にログインします。
2. `サーバーに追加` を選択します。
3. Bot を追加するサーバーを選択します。
4. 表示される権限を確認して、`認証` を押します。

Bot を追加するには、対象サーバーの「サーバーを管理」権限が必要です。
Bot へ管理者権限を付与する必要はありません。

## 使い方

1. Discord でボイスチャンネルへ参加します。
2. ボイスチャンネルの App Launcher を開きます。
3. `読み上げ開始` を選択して Activity を起動します。
4. 読み上げを聞くユーザーも同じ Activity に参加します。
5. ボイスチャンネル内のテキストチャットへメッセージを送信します。

現在の実装では、ボイスチャンネルに参加しているユーザーが、そのボイスチャンネル内の
テキストチャットへ送信したメッセージを読み上げます。

Activity 内では、自分やほかの参加者の話者、速度、音の高さ、感情などを変更できます。
ユーザー辞書から読み方を登録することもできます。

## Bot や「読み上げ開始」が表示されない場合

- Bot がサーバーのメンバー一覧でオンラインになっているか確認してください。
- Bot が対象のボイスチャンネルを閲覧できるか確認してください。
- 自分がボイスチャンネルへ参加しているか確認してください。
- Discord を再起動または再読み込みしてください。
- 一度 Bot をサーバーから削除した場合は、上の招待リンクから追加し直してください。

## セルフホストについて

この Bot は音声合成に VoiceText Web API を使用していますが、同 API の無料利用登録は
終了しています。そのため、新しい API キーを取得してこのリポジトリをセルフホストする
手順は案内していません。上記のリンクから、既に稼働している Bot を追加してご利用ください。

詳細は
[VoiceText Web API 公式 API マニュアル](https://cloud.voicetext.jp/webapi/docs/api)
をご確認ください。
